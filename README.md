### 👨‍💻 About Me

Halo! Saya **Attala Alif Ramadhani Tri Hida (Atta)**, mahasiswa Program Studi **Sistem Informasi di Universitas Trunojoyo Madura (UTM)**. 

Saya aktif mengembangkan solusi perangkat lunak yang memadukan **Cloud Computing & Distributed Infrastructure**, **Artificial Intelligence (Deep Learning & Computer Vision)**, **Mobile Engineering (Flutter & Native Android)**, serta **Full-Stack Enterprise Systems**. Saya selalu berorientasi pada arsitektur yang tangguh, efisiensi komputasi, dan dampak fungsional dunia nyata.

- 🎓 **Pendidikan**: S1 Sistem Informasi — Universitas Trunojoyo Madura (NIM: 230441100144).
- ☁️ **Cloud & Infrastructure**: Berpengalaman merancang arsitektur terdistribusi multi-tier (Hypervisor VirtualBox, Nginx Load Balancer Round-Robin dengan Zero-Downtime Failover, Docker multi-container cluster, dan persistent storage).
- 🧠 **AI & Deep Learning**: Meneliti optimasi model klasifikasi medis (ResNet vs. Vision Transformer pada histopatologi LC25000, Progressive Ablation Study CNN pada CT-Scan paru IQ-OTH/NCCD, dan stratifikasi risiko antenatal KSPR SKI 2023).
- 📱 **Mobile Development**: Mengembangkan aplikasi Android Native (Kotlin Local VPN DNS Packet Filter) dan aplikasi lintas platform berbasis Flutter (NoteCraft, PDF Studio Pro, Bengkel App).
- 🌐 **Web Development**: Membangun web application production-ready dengan Laravel, Node.js/Express, React SPA, serta integrasi Payment Gateway Midtrans.
